# Wiki-Kontext

Wurzelseite dieses Projekts im Wiki des Projekt Managers. Wird von den Skills
`specification`, `documentation` und `feature-editorial` gelesen, bevor sie schreiben
(siehe `reference/wiki-ablage.md` des Plugins `pm-workflow-skills`).

| Feld | Wert |
|---|---|
| Wurzelseite | Seite {{WIKI_ID}} — „{{WIKI_TITEL}}" |
| Projekt | `PROJ-{{PROJEKT_ID}}` — {{PROJEKT_NAME}} |

Unterhalb der Wurzelseite gilt die einheitliche Struktur
`FT(NN): Titel` → `FT(NN) – Use Cases` → `UC (NN/MM): Titel`. Nummern werden nie
wiederverwendet. Neue Seiten immer unter die Sammelseite hängen.
